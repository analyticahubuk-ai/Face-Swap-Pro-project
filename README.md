# Face Swap Project (Web UI)

## Setup
1. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
2. **Launch Server**:
   Double-click `run_server.bat`.

## Usage
1. Open your browser to `http://127.0.0.1:8000`.
2. **Upload** your Source Face (e.g., photo of yourself).
3. **Upload** your 5 Target Videos.
4. Click **Start Face Swap**.
5. Wait for the processing to finish (check standard output mostly for logs, UI will show spinner).
6. **Download** your result videos!

## Troubleshooting
- **Disk Space**: Ensure you have ~500MB free for models + space for videos.
- **Speed**: Without a GPU (NVIDIA CUDA), it might process at ~1-2 FPS.
